## Overview

This portfolio is built for recruiters and hiring managers hiring interns and junior full-stack developers. They often browse on a phone and spend only a short time per portfolio, so everything important sits in one scroll: who I am, my skills grouped as frontend, backend and tools, featured projects with live links and case studies, a contact form, and a one-click resume download.

All content is meant to live in MongoDB. A private admin dashboard will let me add a project (including importing it from a GitHub repo URL), reorder skills, upload a new resume and read messages.


**Live site:** [https://portfolio2-0-seven-liart.vercel.app](https://portfolio2-0-seven-liart.vercel.app)

---

## Features

- Home page with hero, About, Skills, Projects, Research and ML strip, Contact and footer
- Hero "Download resume" button
- Responsive dark purple design for mobile, tablet and desktop
- Case-study page for every project: value statement, live demo and screenshots, stack and features, setup steps, and what I would improve
- Admin dashboard with login, CRUD for projects and skills, and image and resume uploads
- Import a project from a GitHub repo URL
- Contact form that stores messages and emails me
- Link checker for live and repo URLs
- SEO metadata, sitemap and Lighthouse 90+ on mobile
